# Bad Piggies Objects — Geometry Dash 2.2081

Android64 Geode mod that extracts the original **Custom Parts** atlas from Bad Piggies and registers the resulting sprites as editor objects through Object-Collab.

The build workflow validates that the resulting `.geode` actually contains an ELF64/AArch64 native library before publishing the build artifact. A source archive is not an installable mod; use the successful `BadPiggiesObjects-Android64-geode` Actions artifact.
